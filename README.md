# Painel Studio Theodoro

Dashboard de atendimentos, faturamento e tráfego pago do Studio Jessika Theodoro.

- Página única em HTML/CSS/JS, sem build e sem backend.
- Os atendimentos são lidos ao vivo da aba "Respostas ao formulário 1" da planilha publicada do studio.
- A série mensal do Meta Ads fica embutida no arquivo (o token da Meta nunca entra numa página publicada).

Publicado no GitHub Pages para ser incorporado no Google Sites em **Inserir › Incorporar › Por URL**.
